About – Standard / Create Standard Analyte

Please note that Range (Low 0 / High 40) is not the same as “Less than 40 (< 40)”.

  * Range means the result must be between 0 and 40, inclusive. On the report, it will display as 0 - 40.
  * < 40 means the result must be strictly less than 40, and it should display as < 40.

Therefore, if your specification is actually < 40, please do not use Range.

How to Set < 40 Correctly

Use Value is not a free-text field, so you cannot type < 40 directly into it. This is why you received the “standard value id is required” error. You need to select a Specification Value from the list.

Please use the following steps:

  1. Value Type → Use Value
  2. Specification Value → Select IsValue (search for it in the dropdown)
  3. Matrix Operator → < (Less Than)
  4. Actual Value → 40
  5. Click Save

This will display the specification as < 40 and evaluate the result correctly as PASS/FAIL.

If the limit is actually “maximum 40” / “up to 40”, meaning that 40 is also acceptable, then Range 0–40 is appropriate. Alternatively, you can use:

Use Value → IsValue → Max → 40

However, this will not display as < 40 on the report.
